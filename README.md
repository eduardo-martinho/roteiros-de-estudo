# Roteiros de Estudo

Front-end do site Roteiros de Estudo, feito para a Atividade Avaliativa A2 "Do Pedido do Cliente à Interface em Next.js". O aluno do 6º ao 9º ano escolhe a disciplina e o ano e abre um roteiro de estudo gerado por IA e revisado por um professor da rede. O professor pede um roteiro novo por um formulário.

A análise, o plano e o protótipo (Parte 1) estão em `docs/parte1.pdf`. O relatório de execução está em `docs/relatorio.pdf`.

## Como executar

É preciso ter o Node.js 20.9 ou mais novo. Na pasta do projeto:

- `npm install` instala as dependências.
- `npm run dev` abre o site em http://localhost:3000.
- `npm run build` gera o site estático na pasta `out/`.
- `npx serve out` serve a pasta `out/` em http://localhost:3000.
- `npm test` roda os testes das regras de busca e do pedido.
